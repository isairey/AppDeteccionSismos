# 🌍 Sistema de Reporte de Sismos (Web & Móvil)

Plataforma multiplataforma diseñada para el **registro, consulta y monitoreo de sismos**, disponible en versión web y móvil, permitiendo reportar eventos sísmicos y visualizar información en tiempo real.

---

## 📌 Descripción

El **Sistema de Reporte de Sismos** es una solución orientada a recopilar y mostrar información sobre actividad sísmica, facilitando la participación de usuarios y el acceso a datos relevantes.

La plataforma permite reportar sismos, consultar eventos recientes y analizar información desde cualquier dispositivo.

---

## 🚀 Características

- 📱 Aplicación móvil y web  
- 🌍 Registro de reportes de sismos  
- 📍 Ubicación geográfica de eventos  
- 📊 Visualización de datos (magnitud, fecha, profundidad)  
- 🔍 Consulta y filtrado de reportes  
- 🔄 Actualización en tiempo real  
- 🔐 Gestión de usuarios
